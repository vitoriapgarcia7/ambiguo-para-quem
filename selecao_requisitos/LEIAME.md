# Seleção dos requisitos

`selecao_requisitos.xlsx` lista, em ordem, os requisitos com "shall" de cada documento (DigitalHome SRS v1.3 e WARC Tools Phase III), com os 8 selecionados destacados e os 2 excluídos (5.1.3 e FR 19) marcados.

A contagem foi feita automaticamente sobre o texto extraído dos PDFs e deve ser conferida por amostragem. Outra forma de contar (por exemplo, ignorar subitens) muda as posições. A seleção **não foi aleatória** e, no DigitalHome, **não seguiu passo fixo**.

Os PDFs originais **não estão neste repositório**: use o corpus PURE (Ferrari et al., 2017).
